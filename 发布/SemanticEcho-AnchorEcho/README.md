# 语义回响 · 第四代 锚点回响（Anchor Echo, AE）

> **一句话介绍**：这是一套**嵌入空间情感引导引擎**——把模型自己的 token-embedding 权重当"只读情感地图"，给每个词算一个"离温柔/开心/难过/愤怒/害怕/平静有多近"的稠密余弦分，生成时按会话情绪方向**轻推 logits**。不改权重、不重训练、不挂钩子，1.5B 小模型在"人味儿"任务上就能反超裸模型：**HeartBench +21.7% · TuringBench 人似度 +200% · LLM-Judge(+人设) +56.25%**。

> 语义回响家族 P3 锚点回响 AE（最终编号；原第四代。家族链：P1 语义回响 → P1.5 通用兼容层 → P2.5 情感潮汐 ETD → P3 锚点回响 AE → P4 KV 情感共振 KER → P5 超融合解码器 UFD），与前三代**正交可叠加**。

## 1. 四代方案空间对照

| 维度 | P1 语义回响 | P1.5 兼容层 V2 | P2.5 情感潮汐解码 ETD | **P3 锚点回响 AE** |
|---|---|---|---|---|
| 操作空间 | 表示空间（hidden_state） | 配置空间（自动适配） | 概率空间（logits 乘性重加权） | **嵌入空间（token-embedding 权重）** |
| 情感载体 | 回响池质心 | — | 外部 VAD + 稀疏情感词表 | **K 维情感锚点质心 E ∈ R^{K×d}（6 维）** |
| 是否改权重 | 否（hook 只读） | 否 | 否 | **否（sum/data_ptr 断言零修改）** |
| 打分密度 | 全词表稠密（随机投影） | — | 稀疏（≈千级 token） | **全词表稠密但低秩（S ∈ R^{V×K}）** |
| 闭源 API | 不可用 | 提示级 | 部分 | **三级降级（embedding→logprobs→提示）** |
| 注入内存 | 投影矩阵 ≈933MB fp32 | — | 词表 dict ≈KB | **打分表 1.8MB fp16（1.5B）** |

## 2. 三层架构（感知 / 目标 / 表达）

```
用户消息 ─→ 潮汐感知器.测量() ─→ 潮汐决策器.计算目标() ─→ V_target / α
     │                                                       │
     │── 思考链注入器（可选）──────────────────────────────────→ 目标决策器: v_target, β
     │── 显式情感指令（可选）──────────────────────────────────→│
     └────────────────────────────────────────────────────────┘
                                                          ↓
    模型前向(logits) ── ① 回响 ── ② 潮汐 ── ③ 锚点解码器.注入偏置 ── 采样 → 输出
```

| 层 | 模块（`锚点回响核心/`） | 职责 |
|---|---|---|
| 目标层 | `目标决策器.py` | VAD→锚点映射（方向余弦+平方放大）、共情公式、多源融合、角色感知（0.7·角色+0.3·用户）、自动适配 β |
| 表达层 | `锚点库.py` | 6 维情感锚点质心（每维 50 中文种子词，含流行语：破防/泪目/内耗/扎心）、预计算打分表 S ∈ R^{V×K}、只读校验 |
| | `锚点解码器.py` | `logits[w] += β·tanh(S[w]·v_target/T_anchor)`（有界防坍缩）、生成循环、在线退化兜底 |
| | `混合锚点器.py` | 锚点 × 回响 × 潮汐 三通道正交叠加（logits 加法、独立开关） |
| | `接口降级.py` | `判定接口()` 三级降级判定、`构造提示词()` 黑盒提示模板 |

**核心公式**：打分表 `S[w,k]=cos(W_e[w], e_k)`；目标 `v_target = w_潮汐·v_潮汐 + w_思考链·v_思考链 + w_指令·v_指令`（L2 归一化）；注入 `logits[w] += β·tanh(S[w]·v_target / T_anchor)`；自动适配 `β = 扫描表或公式 × 架构族因子 × 量化因子`。

**最优配置**（Task5 定标，3 种子均值）：**(β=0.8, 稀疏阈值=0.0, T_anchor=0.3, K=6)** —— 熵 2.0291（裸的 109.9%，不退化）、重复率 0.0787（裸 0.1336，无坍缩）、情感命中率 0.1279（裸 0.0979，提升）。

**三级接口降级**（闭源 API 可用）：① 本地 embedding 直读（主路径，全词表稠密）→ ② API logprobs 近似（top-100 受限注入，与全词表**熵差仅 0.67%、输出逐字一致**）→ ③ 锚点提示模式（纯黑盒，零内部访问、方向正确）。

## 3. 五基准评测结果（Qwen2.5-1.5B fp16，裸 vs P3 锚点，同种子 42，7B 裁判）

| 基准 | 指标 | 裸 | P3 锚点 | Δ/相对 | 判定 |
|---|---|---|---|---|---|
| **HeartBench**（20 题） | overall | 35.90 | **43.69** | **+21.7%** | ✅ 显著提升（P2.5 潮汐同基准 -9.4%） |
| **TuringBench**（30 测试对） | human_likeness | 0.2333 | **0.7000** | **+200.0%** | ✅ 大幅提升 |
| **LLM-Judge**（60 配对） | win_rate（单模式纯净） | 0.2667 | 0.3000 | +12.49% | 部分达成 |
| | win_rate（+P2.5 人设） | 0.2667 | **0.4167** | **+56.25%** | ✅ 达成 |
| **HEART-BENCH**（10 题） | 共情分 | 0.76 | 0.72 | -5.26% | △ 边缘持平（与 P2.5 同档） |
| | 一致性 / 有效决策率 | 0.60 / 1.0 | 0.65 / 1.0 | +8.3% / 0 | ✅ |
| **EmoCharacter**（10 角色） | 匹配 fidelity | 0.8300 | 0.8075 | -2.7% | ✅ ≥裸-5% |
| | 一致性识别率 | 0.9000 | 0.7000 | -22.2% | ❌ 1.5B 天花板限制（固有开头模板+打乱集雷同） |

**多模型泛化**（LLM-Judge，β 自动适配）：Qwen3-1.7B **+6.91%** ✅、gemma-2-2b **+28.53%** ✅（公式兜底路径成立且增益最大）、Qwen2.5-3B -5.86%（60 配对差 1 胜，方差内负向）；**3/3 模型无坍缩、情感命中率均 ≥ 裸**。

**三裁判交叉验证**（三正交叠加：裸/锚点/回响/全开，控制变量只变裁判）：本地 7B 与 DeepSeek pro 下全开均优于裸（相对 +55.6% / +100%，方向跨裁判一致），全开熵 1.42→1.67（+17%）、回复长度 135→54 字对齐真人、无坍缩；卡点＝1.5B 原生 AI 腔未抑制（纯净模式），需与人设叠加兑现增益。

## 4. 快速开始

```bash
pip install torch transformers cnsenti
python 快速开始.py
```

`快速开始.py` 演示完整链路：**加载模型 → 构建锚点（6 维质心 + 打分表）→ 目标决策器 → 锚点解码器生成 → 打印熵/重复率/情感命中率 + 只读校验**。三级降级用法：`锚点解码器(..., 接口="logprobs")` 或 `接口="提示"`；三通道叠加用 `混合锚点器.py`。

> **注意**：`目标决策器.py` / `混合锚点器.py` 顶部硬编码了作者本机 P2.5 工程路径（`h:\情感潮汐解码（Emotion Tidal Decoding, ETD）`、`i:\Desktop\语义回响`），缺失时自动降级（内置简易 VAD / 关闭回响通道），不影响锚点主链路；完整 VAD 与回响通道请在复现时改为你自己的 P2.5 路径。
