## 概述

语义回响是一种不修改模型权重、不重新训练的推理增强方案。
通过在推理过程中回收被丢弃 Token 的嵌入向量，将其作为"情感底色"
持续影响后续输出，增强语言模型的情感表达细腻度。

## 核心发现

| λ 强度 | 语义熵变化 | 效果 |
|--------|-----------|------|
| λ=0（基线） | — | 标准推理 |
| λ=0.5（弱回响） | **+17.9% ↑** | 表达更细腻 |
| λ=1.0（中回响） | -60.0% ↓ | 出现重复倾向 |
| λ=2.0（强回响） | -89.4% ↓ | 严重重复 |

**λ 与语义熵呈非单调（U型）关系**，存在最佳强度阈值。
